Updraft Aces: privacy

This game collects no data.

  • No accounts and no sign-in.
  • No ads and no trackers.
  • The game makes no network calls. The Android app does not ask for the internet permission.
  • Your settings and saved games stay on your device. Deleting the app, or clearing this site's data in your browser, removes them.

This page is hosted on GitHub Pages. GitHub may log visits to the page itself, as any web host does. The game sends nothing.

Play count. Tapping Play in your browser on the game page adds one to a public count of plays for this game, shown on the game page and on The Game Shelf. A free counting service, Abacus (abacus.jasoncameron.dev), keeps the count. The tap sends the game's name and nothing else: no name, no account, no cookie and no player ID. Abacus sees your IP address when the count goes up, as any web host does. The game itself still sends nothing.
