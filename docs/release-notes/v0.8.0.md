# Updraft Aces v0.8.0

Reasons to fly a stage again: medals, formation chains, flak you can shoot down and bigger points on Ace.

## Five minute test

1. Open the Menu. Each stage row shows its medals, like "0 of 4 medals". A stage you have not opened says "(locked)".
2. Fly Cloud Harbor from the start. Break formations back to back. The pop reads "+1200  Chain x2", then x3, and so on. Let a plane get away and you see "Chain broken".
3. In Amber Canyon, shoot a flak shell before it bursts. It pops for +150 and no ring of bullets comes out.
4. Clear a stage. The banner lists any new medals.
5. Try Ace. Every point is worth half again as much.

## New in this version

- Medals (idea 15): four per stage, earned in one run from the start of the stage.
  - Sweep: break nine in ten formations.
  - Untouched: take no hits.
  - Daredevil: roll through 10 bullets.
  - Top Ace: clear it on Ace (this one counts from a checkpoint too).
  - A new achievement, Medal Case, for every medal on every stage.
- Formation chain (idea 16): each formation you break in a row pays a quarter more, up to 9 in a row. A plane that gets away breaks the chain. A rewind starts it again.
- Shootable flak (idea 17): your shots pop flak shells for 150 points before they burst.
- Ace points (idea 18): Ace pays 1.5 times the points.
- Stage table (idea 27): each stage's music, art, bullet colors and clear reward sit in one table, and the Menu rows are built from it. Stage 3 is now mostly a new row and new art.
- The Menu rows refresh each time the Menu opens, so medals and locks are always current.

## Shared kit

Built with kit 1.22.0.

## Install

Installs over every earlier version. Save slots stay, and medals save with the slot.

## Full test checklist

1. Day one, save (medals now included), medal (new), assist, power-up, tester note and pressure checks: passed.
2. Bot clears both stages on Breeze, Standard and Ace. On Standard the bot earns Sweep and Untouched. On Ace it earns Daredevil and Top Ace.
3. Every kit check: passed.
4. Browser: day one, Stage 2, power-ups, review on a phone-sized screen and wide screens: passed.

## Not tested

The APK on a real phone.

## Judgment calls

- Sweep needs nine in ten formations, not all of them. On Ace the mirrored swoops make every single one very hard.
- Medals other than Top Ace need a run from the top of the stage. A run that resumes at a checkpoint can't earn Untouched or Sweep.
- The pressure check counts a flak shell as its ring of 8 bullets, since shooting it down is now a choice.
- Rescue pickups (idea 20) would make a natural fifth medal later.
