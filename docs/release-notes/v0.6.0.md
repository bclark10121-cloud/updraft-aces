# Updraft Aces v0.6.0

A painted start screen, a trademark search for the name and three pieces of this game moved into the shared kit.

## Five minute test

1. Open the game. The start screen has a painted sun, puffy painted clouds drifting by and a painted cloud bank under the dock.
2. Play a minute of Cloud Harbor and a minute of Amber Canyon (Menu > Stage 2). Both should play exactly like 0.5.0.
3. Open Settings. The five assists are still there and still work.
4. Unlock Tester tools, press F8 or the Note button, draw with the red marker, save and export. The zip is still named updraft-aces-notes.zip.

## New in this version

- Painted start screen (item 1): Gemini painted the sun, three side-view clouds and the cloud bank in the same toy style. The sun's warm glow is drawn by the game.
- Trademark search (item 2): no mark named Updraft Aces at the USPTO. The nearest live mark is LINK UPDRAFT, for casino and sweepstakes machine software. Notes in `docs_name_check.md` in the game folder.
- Shared kit (items 4, 5 and 6): the game now runs on kit 1.22.0. The wave runner (K2 Waves), the easy pack (K8), the LDtk stage reader and the tester note tool (T1) come from the kit. The game's own copies are gone, so every future shooter gets them for free.
